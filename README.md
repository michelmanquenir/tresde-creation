# tresde-creation

Frontend de la tienda de impresiones 3D (React + TypeScript + Vite).

## Desarrollo

```bash
npm install
npm run dev
```

## Estructura

- `src/data/catalog.ts`: categorías y productos de ejemplo
- `src/components/`: navbar, footer, carrito, tarjetas de producto
- `src/pages/`: inicio, categoría/búsqueda, producto, pedido a medida
